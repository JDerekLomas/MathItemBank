# Accessibility & Equity Skills - Inclusive Assessment Design

## 1. Physical & Sensory Accessibility (5 Skills)

### 1.1 visual-accessibility-validator
**Purpose**: Ensure visual accessibility and screen reader compatibility
**Focus**: Color contrast, font size, visual clarity, screen reader optimization

### 1.2 hearing-accessibility-validator
**Purpose**: Validate hearing accessibility and audio content
**Focus**: Captioning, visual alternatives, audio descriptions, volume control

### 1.3 motor-accessibility-validator
**Purpose**: Ensure motor accessibility and interaction design
**Focus**: Keyboard navigation, touch targets, interaction timing, alternative input

### 1.4 cognitive-accessibility-validator
**Purpose**: Validate cognitive accessibility and information processing
**Focus**: Memory load, attention requirements, processing time, clarity

### 1.5 seizure-safety-validator
**Purpose**: Ensure seizure safety and visual comfort
**Focus**: Flashing content, contrast sensitivity, visual stress reduction
