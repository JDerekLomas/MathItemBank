# Content Generation Skills - Core Item Creation Workflows

## 1. Basic Item Generation Skills

### 1.1 equation-item-generator
**Purpose**: Generate algebraic equation solving items across difficulty levels
**Description**: Creates items focused on linear, quadratic, and polynomial equations with real-world contexts
**Input**: Standard, difficulty level, equation type
**Output**: Formatted equation item with distractors and solution

### 1.2 word-problem-creator
**Purpose**: Transform mathematical concepts into authentic word problems
**Description**: Converts abstract mathematical procedures into relatable real-world scenarios
**Input**: Mathematical concept, target grade, context theme
**Output**: Contextualized word problem with solution explanation

### 1.3 formula-application-generator
**Purpose**: Create items requiring formula application and manipulation
**Description**: Generates problems involving area, volume, surface area, and other geometric formulas
**Input**: Formula type, complexity, contextual application
**Output**: Multi-step formula application item with verification steps

### 1.4 function-analysis-generator
**Purpose**: Generate function analysis and interpretation items
**Description**: Creates items for graphing, domain/range, and function behavior analysis
**Input**: Function type, analysis focus, representation method
**Output**: Function analysis item with graphical component

### 1.5 data-interpretation-generator
**Purpose**: Create data analysis and statistical interpretation items
**Description**: Generates items involving tables, charts, and statistical reasoning
**Input**: Data type, analysis question, visualization format
**Output**: Data interpretation item with visual component
